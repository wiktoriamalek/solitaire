# C++ Solitaire

A terminal-based Klondike solitaire game. The program deals a shuffled 52-card deck, displays the tableau, and lets you move cards between the draw pile, seven working piles, and suit foundations.

## Requirements

- A C++ compiler with C++11 support

## Build and run

From the repository root:

```bash
g++ -std=c++11 -pthread -x c++ main-3.cp -o solitaire
./solitaire
```

Choose **Start a new game** from the menu and follow the prompts in the terminal.
